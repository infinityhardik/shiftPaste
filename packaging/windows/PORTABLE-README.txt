Shift Paste (portable)

Run shiftpaste.exe. Because the "ShiftPaste-data" folder sits next to it,
your history, collections and settings are stored in that folder, so they
travel with the app (for example on a USB stick).

Delete the "ShiftPaste-data" folder to use the normal per-user location
instead. Press Ctrl+Shift+V anywhere to open Shift Paste.
